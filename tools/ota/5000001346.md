## Получение образа

Для начальной адаптации boot был зашифрован, а AF_ALG недоступен из домена
`shell`. Образ снят read-only через физическое окно CVE-2022-36449 по
одиннадцати фрагментам (до 504 страниц каждый), начиная с PA `0x1080000`.

После получения root на этой же станции boot расшифрован штатным путём
через AF_ALG (`cbc(aes-kl-aml)`, селектор `0x86`); SHA-256 payload совпал
с ожидаемым. Адреса профиля независимо проверены по расшифрованному OTA:
таблицам символов, данным и дизассемблированному коду.

Побайтное совпадение всего снимка RAM с OTA не ожидается: при загрузке
применяются патчи инструкций и релокации, меняются данные и BSS,
освобождается и переиспользуется init-память. Проверенные диапазоны
`kallsyms_names`, `kallsyms_token_table` и строки версии совпали побайтно;
это не проверка неизменности всех страниц снимка.
