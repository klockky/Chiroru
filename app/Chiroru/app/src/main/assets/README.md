# Ресурсы APK

- `firmware/profiles.json` — признаки прошивок, пути ресурсов и SHA-256.
- `firmware/<profile-id>/` — модули `kernelsu.ko` и `chiroru_adb.ko` для конкретного ядра.
- `firmware/chiron-1982735225/` также содержит armv7-клиент, демон и менеджер factory.
- `firmware/chiron-1926931523/` содержит отдельные модули factory-профиля;
  клиент, демон и менеджер используются из `chiron-1982735225` через каталог.
- `common/` — общие клиенты и демоны.

Загрузчик выбирает ресурсы по профилю, извлекает их в device-protected storage
и проверяет хеши перед запуском. Сборка APK также сверяет каталог и файлы.

При замене ресурса обновите его SHA-256 в `profiles.json`.

[сборка модулей](../../../../../../tools/KERNEL_MODULES.md),
