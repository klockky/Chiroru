# Бинарные ресурсы

Ядро-модуль скопирован из исходного приложения `mali36449 probe`; `ksud` взят
из установленного KernelSU-Next на тестовой колонке, чтобы совпадал UAPI ядра:

| Файл | Размер | Происхождение |
|---|---:|---|
| `ksu.ko` | 8 518 072 байта | KernelSU-Next v3.4.0-legacy, модуль для исходного ядра 5.4 |
| `ksud` | 7 059 584 байта | KernelSU-Next 3.4.2, UAPI 5, ARM64 / Android |

Это входные бинарники сборки. Их исходный код не добавляется этим переносом.
Chiroru извлекает их в private device-protected storage; `ksud` обновляется из
APK при операции загрузки модуля, чтобы прежняя несовместимая копия не осталась
в хранилище приложения. SHA-256 `ksud`:

```text
7794fb0546955e10b3b61a2771b325d52e47ac1d4702970c9a46e3b1667db042
```
