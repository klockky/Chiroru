# Chiroru

Root для Яндекс Станции Дуо Макс: консоль в приложении, ADB root и KernelSU.
Использует CVE-2022-36449 в драйвере ARM Mali, без прошивки boot-раздела.

## Установка

Скачайте `Chiroru.apk` из [последнего релиза](https://github.com/klockky/Chiroru/releases/latest).

Установите APK, выберите способ в настройках и нажмите **«Получить root»**.
На factory сначала нажмите **«Установить совместимый менеджер»** для KernelSU.

In-app root работает до закрытия процесса Chiroru, ADB root и KernelSU —
до перезагрузки станции. Автозагрузка KernelSU включается в настройках.
Задержка **0** запускает её по первому boot-событию Android. Если успешная
загрузка не подтверждена, автозапуск блокируется до ручного возобновления
в настройках. [Подробности защиты](app/Chiroru/README.md#автозагрузка).
Там же можно включить поддержание ADB: проверка каждые 30 секунд и включение
при необходимости. Разрешение выдаётся автоматически после успешного root.
